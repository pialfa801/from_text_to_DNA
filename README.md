# from_text_to_DNA
This is just a silly code I made on Python after like a month of Programming 101 in my Master's Degree based on hellsitegenetics's posts.

If someone finds this without knowing anything about hellsitegenetics, it's a gimmick Tumblr blog that takes posts, erases all the letters except A, C, T and G and uses BLAST with the remaining sequence. After learning a bit about the things you can do with strings, I thought you could make the process a lot less tedious with coding. You still need to manually put the sequence on BLAST because for some reason I wasn't able to automate it. However, this still takes a lot of the job of erasing every single non ACTG letter.

I added a step of changing all diacritic letters so it's compatible with non-English texts. If there's any letter like this that I have forgotten, I apologize.
